Frequently Asked Questions

What is Movie Lookup?

Movie Lookup is a demo project for browsing and searching movies, built with a Node/Express backend and the OMDb API.

How much does it cost?

This is a personal project - it's free to run locally.

Where can I watch?

Anywhere you can run this project - it's a browser-based demo app.

How do I search for movies?

Sign in to browse, then use the search bar to look up any title via the OMDb database, including posters, synopsis, and cast.
